WhatsApp Not Sending a Verification Code: Why and How to Fix It

Short answer

WhatsApp checks every number before sending a code and refuses many VoIP numbers and numbers already used for other accounts. Make sure the country and number are correct, wait for the timer, use "Call me", and if WhatsApp still refuses, the number type is the problem, not your phone.

Step by step

How to Fix It

  1. Check country and number

    Choose the country from the list, then type the number without the leading 0 or country code.

  2. Wait for the timer

    WhatsApp shows a countdown. Requests before it ends do nothing.

  3. Choose "Call me"

    When the SMS timer ends, ask for a voice call and note the 6-digit code.

  4. Stop after two tries

    If both SMS and call fail, the number is being refused. More attempts lock it longer.

  5. Switch to a number that passed

    See which services passed WhatsApp in our ranking.

Avoid

What Not to Do

  • Do not register WhatsApp with a public receive-SMS number: anyone can take the account later.
  • Do not use unofficial WhatsApp apps to get around verification.
  • Do not forget to set a two-step verification PIN after signing in.

FAQ

Questions People Ask

Why does WhatsApp not send a code to my virtual number?

WhatsApp checks the line type and history of the number. Most free virtual numbers are VoIP lines, and WhatsApp refuses them without sending anything.

How long should I wait before requesting a new code?

Wait until the countdown ends. After several failed tries the wait can grow to hours.

Can someone else take my WhatsApp if I use a public number?

Yes. Whoever gets the number next can request a code and move the account to their phone. Set a two-step PIN to make this harder.
